# 使い方

get-md の全オプションと、README より多い使用例、セレクタとファイル出力の挙動をまとめています。端末では `get-md --help` で同じオプションの一覧を確認できます。

## 書式

```bash
get-md [OPTIONS] <URL>
```

`<URL>` には取得するページを指定します。ローカルのファイルも `file://` の URL で指定できます。

## オプション

| オプション | 短縮形 | 説明 |
|---|---|---|
| `--selector <SEL>` | `-s` | 変換する要素の CSS セレクタ (複数指定可)。省略するとページ全体 (`body`) を変換 |
| `--output <FILE>` | `-o` | 出力先のファイル (既定: 標準出力) |
| `--chrome-path <PATH>` | | Chrome / Chromium の実行ファイルのパス (既定: 自動で検出) |
| `--wait <SECS>` | `-w` | ページの読み込み後、JavaScript の描画を待つ追加の秒数 (既定: 2) |
| `--timeout <SECS>` | `-t` | ページの読み込みのタイムアウト秒数 (既定: 60) |
| `--no-headless` | | ブラウザのウィンドウを表示する (デバッグ用) |
| `--no-cache` | | ブラウザのキャッシュを無効にする (常に最新の内容を取得) |
| `--ignore-certificate-errors` | | HTTPS の証明書エラーを無視する (危険: 信頼できるサイトのデバッグに限る) |
| `--ignore-date` | | ファイルに書き込むとき、日時だけの差分を変更なしとして扱う |
| `--front-matter` | | 取得元の情報を YAML の front matter として出力の先頭に付ける ([front matter](#front-matter) を参照) |
| `--meta <KEY=VALUE>` | | front matter に自分で決めた項目を足す (複数指定可)。`--front-matter` も有効になる |
| `--keep-hidden` | | ページの上で見えなくされた要素とテキストも取り出す (従来の動作。[見えなくされた内容と見えない文字](#見えなくされた内容と見えない文字)を参照) |
| `--keep-invisible` | | ゼロ幅スペースや双方向の制御文字などの見えない文字を出力に残す (従来の動作) |
| `--quiet` | `-q` | 進捗の表示を止める |
| `--help` | `-h` | ヘルプを表示する |
| `--version` | `-V` | バージョンを表示する |

ブラウザ側のアイドルタイムアウトは、`--timeout` と `--wait` に 30 秒を足した値です。静かなページで JavaScript の描画を待つ間も、Chrome DevTools Protocol の接続を保ちます。この足し算は上限で頭打ちになるため、極端に大きな値を指定してもオーバーフローしません。

## 使用例

```bash
# ページ全体を Markdown に変換して標準出力に書き出す
get-md https://example.com

# 見出しだけを抽出する
get-md https://example.com -s "h1"

# 複数の要素を抽出する (結果は指定した順に --- でつながる)
get-md https://example.com -s "h1" -s "p"

# ファイルに保存する
get-md https://example.com -s "h1" -s "p" -o example.md

# 描画の遅いページに合わせて、読み込み後に 5 秒待ち、読み込み自体は 90 秒まで待つ
get-md https://example.com -w 5 -t 90

# Chrome の実行ファイルを指定する (macOS)
get-md https://example.com --chrome-path "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

# 証明書に問題がある信頼済みのページを取得する (ここでは公開されている自己署名のテストページ)
get-md https://self-signed.badssl.com/ --ignore-certificate-errors

# 日時だけが変わった場合はファイルを書き換えない
get-md https://example.com -o example.md --ignore-date

# 取得元の URL・タイトル・セレクタ・取得した時刻を YAML の front matter に残す
get-md https://example.com -o example.md --front-matter

# front matter に自分で決めた項目を足す (--meta だけでも front matter が付く)
get-md https://example.com -o example.md --meta topic=example --meta "note=参考に保存"

# スクリプトで保存済みのページを取り直す (ページが本当に変わったときだけファイルが変わる)
get-md https://example.com -o example.md --front-matter --ignore-date --meta topic=example

# 折りたたまれた節や閉じたタブなど、ページの上で見えなくされた内容も取り出す
get-md https://example.com --keep-hidden

# 以前の版と同じ出力にする (見えなくされた内容も見えない文字も残す)
get-md https://example.com --keep-hidden --keep-invisible

# 進捗を表示せずに実行する
get-md https://example.com -q -o example.md
```

## セレクタ

- `-s` を省略すると、ページ全体 (`body`) を変換します
- `-s` を複数指定すると、指定した順に結果を並べ、間に `---` の行を挟みます
- 何にも一致しないセレクタがあると、警告を表示します。どのセレクタも一致しなかった場合は、エラーで終了します
- 不正な CSS セレクタは「一致なし」ではなく、エラーとして報告します
- 一致した要素そのものがページの上で見えない場合や、見えない要素の中にある場合は、警告を表示してその要素を出力しません。一致した要素がどれも見えない場合は、`--keep-hidden` を案内するエラーで終了します ([見えなくされた内容](#見えなくされた内容)を参照)

## 取得

- **HTTP エラー**: HTTP のステータスを Chrome DevTools Protocol のネットワークイベントから読み、404 などのエラー応答を拒否します。ページのスクリプトがブラウザの Performance API を書き換えても、判定は変わりません
- **証明書**: HTTPS の証明書は既定で検証します。`--ignore-certificate-errors` は、デバッグ中の信頼できるサイトにだけ使ってください
- **キャッシュ**: `--no-cache` を付けるとブラウザのキャッシュを使わず、毎回最新の内容を取得します

## ファイルへの出力

`-o` を付けると、Markdown をファイルに書き込み、そのファイルがどうなったかを表示します。

```text
✨ https://example.com → example.md (created)
```

| 印 | 状態 | 意味 |
|---|---|---|
| ✨ | created | ファイルが無かったので新しく作った |
| 📝 | updated | 内容が変わった |
| ✔ | unchanged | 内容が前と同じ |

- **Git を考慮した判定**: 出力先が Git で追跡されていて、ステージしていない変更がある場合は `updated` と表示します。判定は出力先を含むリポジトリで行い、パスはそのまま照合します (名前に含まれる `[` や `*` などの glob の文字は展開しません)。そのため、削除した追跡ファイルに書き出す場合や、そのリポジトリの外で get-md を実行した場合も正しく判定できます。既存のファイルを読み取れない場合は `updated` として扱います
- **`--ignore-date`**: 日時の文字列だけが変わった場合は、書き換えを省きます。小数秒やタイムゾーン付きの一般的な ISO 8601 の形式も対象です。古い内容と新しい内容の両方に日時が含まれる場合だけ比較し、UTF-8 でないファイルは通常の比較に戻します
- **アトミックな書き込み**: 出力は同じディレクトリの一時ファイルに書いてから rename で置き換えるため、書き込みの途中で I/O エラー (ディスクの容量不足など) が起きても、既存のファイルが切り詰められたり壊れたりしません。既存のパーミッションは内容を書く前に適用し、書き込み権限は先に確かめます。出力先がシンボリックリンクなら実体に書き込み、リンクはそのまま残します。リンク先がまだ無く、その親ディレクトリも無い場合は、親ディレクトリから作ります。rename は inode を置き換えるので、ハードリンクは切れ、ACL と拡張属性は引き継がれません (クラッシュへの強さを優先した仕様です)
- **進捗**: 進捗は標準エラー出力に表示するので、標準出力に書き出す Markdown には混ざりません。完了の表示は、出力の書き込みと flush に成功してから出します。見えなくされた内容や見えない文字を除いたときは、完了の表示の後にその数を表示します ([表示する数](#表示する数)を参照)
- **front matter**: `--front-matter` を付けると、取得した時刻を比較から外します。詳しくは[既存のファイルとの比較](#既存のファイルとの比較)を参照してください

## front matter

`--front-matter` を付けると、出力の先頭に YAML の front matter を付けます。ファイルだけでなく標準出力にも付くので、保存した写しに取得元の記録が残ります。`--meta KEY=VALUE` は自分で決めた項目を足し、これだけでも front matter が付きます。

```bash
get-md https://example.com -o example.md --meta topic=example
```

```markdown
---
url: "https://example.com"
title: "Example Domain"
selectors: ["body"]
retrieved_at: "2026-09-29T03:10:00Z"
topic: "example"
---

# Example Domain
```

### 項目

項目はいつも次の順に並びます。

| 項目 | 値 | 書く条件 |
|---|---|---|
| `url` | 引数に渡した URL (そのまま) | いつも |
| `final_url` | リダイレクトなどを経て読み込んだ後のページの URL | `url` と違うときだけ。`https://example.com` と `https://example.com/` の末尾の `/` のように、URL の正規化で消える違いは数えない |
| `title` | ページの `document.title` から見えない文字を除き (`--keep-invisible` のときは除かない)、前後の空白を削ったもの | ページに空でないタイトルがあるときだけ |
| `selectors` | 使ったセレクタの一覧。`-s` を省くと `["body"]` | いつも |
| `retrieved_at` | ページを読んだ時刻。UTC の RFC 3339 で、秒まで | いつも |
| `--meta` の項目 | 指定した値。指定した順に並ぶ | `--meta` を指定したとき |

get-md の版は書きません。get-md を上げるたびに、保存したすべてのファイルが書き換わるのを避けるためです。

### 書式

- `---` の行、項目ごとの `key: value` の行、閉じの `---` の行、空行の順に書き、その後に Markdown が続きます。閉じの `---` の後にはいつも空行があるので、本文が `---` で始まっても区別できます
- 値はすべて YAML のダブルクォートの文字列で、`selectors` はダブルクォートの文字列を並べたフロー形式の列 (`["article", "main"]` など) です。そのため `true` や `2026-09-29`、`a: b` のような値も文字列として読まれます
- クォートの中では、`"` と `\` をエスケープし、改行・復帰・タブを `\n`・`\r`・`\t` に、そのほかの制御文字と U+2028・U+2029・U+FEFF・U+FFFE・U+FFFF を `\uXXXX` にします。どの項目も 1 行に収まり、YAML のパーサで読むと元の文字列に戻ります

### `--meta` の決まり

- 引数は最初の `=` で分けます。`--meta query=a=b` なら、`query` の値は `a=b` です。値は空でもかまいません (`--meta note=`)
- 値は渡したとおりに書きます。ページのタイトルと違い、見えない文字も除きません
- キーは英字か `_` で始め、英数字・`_`・`-` だけで書きます (`^[A-Za-z_][A-Za-z0-9_-]*$`)
- 次の場合はブラウザを起動する前にエラーで終了します: `=` がない、キーが空、キーの書式が違う、同じキーを 2 回以上指定した、組み込みの項目 (`url`・`final_url`・`title`・`selectors`・`retrieved_at`) と同じキー、YAML が文字列ではなく真偽値や null として読む語 (`true`・`false`・`null`・`yes`・`no`・`on`・`off`・`y`・`n`。大文字小文字を問わない)

### 既存のファイルとの比較

`-o` の出力先に get-md の front matter 付きのファイルがすでにあるときは、新しい出力と次のように比べます。

- `retrieved_at` の値は、`--ignore-date` の有無にかかわらず、いつも比較から外します。ほかの項目と本文が同じなら、ファイルを書き換えずに `unchanged` と表示します (Git でステージしていない変更があれば、これまでどおり `updated`)。変わっていないページを取り直しても、Git の差分は出ません
- `--ignore-date` も付けたときでも、front matter (`retrieved_at` を除く) は文字列どおりに比べ、日時の差分を無視する比較は本文にだけ当てます。タイトル・URL・セレクタ・`--meta` の値の変化は必ず書き込みます
- 既存のファイルに front matter がない場合 (初回や、ヘッダの形式が違う場合) は、これまでどおりファイル全体を比べるので、front matter を付けて書き直します
- `retrieved_at` は、ファイルに保存している本文を取得した時刻を表します。ファイルを書き換えなかったときは、前の値が残ります
- 既存のファイルの front matter にしかない項目は引き継ぎません。出力は引数だけで決まります。残したい値は、毎回 `--meta` で渡してください

`--front-matter` も `--meta` も付けないときの出力と比較は、これまでと変わりません。

## 見えなくされた内容と見えない文字

ページの上で人に見えない文字列も、Markdown にすれば AI (LLM) はそのまま読みます。CSS や見えない文字で隠した指示でモデルを操ったり (プロンプトインジェクション)、紛れ込んだ制御文字で動きを乱したりできてしまいます。そこで get-md は既定で次の 2 つを除き、モデルが読む内容を人が画面で見る内容に近づけます。

- **見えなくされた内容**: 描画したページの上で見えなくされた要素とテキスト。`--keep-hidden` を付けると残します
- **見えない文字**: ゼロ幅スペース・BOM・双方向の制御文字・タグ文字・制御文字など、表示されない文字。`--keep-invisible` を付けると残します

どちらも見える表記に置き換えず、消します。2 つのオプションは互いに影響しません。

> **既定の出力が変わりました。** 以前の版はどちらも残していました。以前と同じ出力が必要なときは `--keep-hidden --keep-invisible` を付けてください。

### 見えなくされた内容

見えるかどうかは、HTML を取り出す時点 (`--wait` の待ち時間の後) の描画済みのページで、ブラウザの計算済みスタイルから判定します。除くのは選んだ要素の複製からで、ページそのものは変えません。判定はページのスクリプトから切り離した実行環境 (ブラウザの拡張機能と同じ isolated world) で動かします。ページが JavaScript の関数を書き換えても、判定は止まらず、結果も偽れません。

次の要素は、中身ごと除きます。

| 条件 | 例 |
|---|---|
| `display: none` | `hidden` 属性の付いた要素 (CSS で上書きされていなければ)、閉じた `<dialog>`、表示していないポップオーバー、閉じたメニューやタブのパネル |
| `content-visibility: hidden` | `hidden="until-found"` |
| 要素そのものの `opacity: 0` | 後からフェードインする内容 |
| 閉じた `<details>` の、`<summary>` 以外の子 | `<summary>` は残す |
| 画面から隠す形 (visually-hidden): 絶対配置か固定配置で、面積 0 の `clip: rect(...)` か全体を切り取る `clip-path: inset(...)` で切り抜かれ、大きさが 1px 以下 | `.sr-only` や `.visually-hidden` のクラス |
| ページの左か上の外: 絶対配置か固定配置で、スクロールしても届かないページの左か上の外に完全に出ている | `left: -9999px`、`top: -500px` |

次の場合はテキストの単位で除きます。要素は残すので、子が自分の文字を表示していればその文字は残ります。

| 条件 | 補足 |
|---|---|
| `visibility: hidden` か `collapse` | 子で `visibility: visible` に戻した文字は残す |
| `font-size: 0` | |
| 透明な文字色 (`color` か `-webkit-text-fill-color` の不透明度が 0) | 文字の縁取り・文字の影・文字の形に切り抜いた背景 (`background-clip: text`。グラデーションの見出しなど) で字形が見えるときは残す |
| 閉じた `<details>` の直下の文字 | |

- 空白だけのテキストは判定しません。`script`・`style`・`noscript`・`template`・`svg` と、`title` や `meta` などの head の要素はそのまま残します (script・style・noscript・SVG は Markdown に変換するときに捨てます)
- ページの外の判定は横書きのページだけで行い、左の外は左から右へ書くページだけで判定します。右から左へ書くページや縦書きのページは、左や上へスクロールできるためです。はみ出した中身がページの中に届いている要素は残します
- 選んだ要素そのものが見えない場合や、見えない要素の中にある場合は、警告を表示してその要素を出力しません。選んだ要素がどれも見えない場合は、`--keep-hidden` を案内するエラーで終了します

**get-md が読んだ時点のページの表示を基準にします。** 閉じたタブ・アコーディオン・`<details>`、開いていないメニュー、スクロールで表示するアニメーションがまだ表示していない内容 (スクロールで近づくまで `opacity: 0` のままのもの。get-md はスクロールしません) は除かれます。必要なときは `--keep-hidden` を付けてください。

次のものは除きません。文字を隠していないか、見えるかどうかを軽い処理で確実に判定できないためです。

- `aria-hidden="true"`: 支援技術から隠すだけで、文字は画面に表示されています
- とても小さい文字 (`font-size` が 0 より大きいもの) と、切り抜かれていない 1px 以下の要素
- ページの右や下の外にある内容 (スクロールすれば見える) と、`text-indent` で外へずらした文字
- 背景と同じ色の文字: 実際の背景は画像・グラデーション・重なった要素で決まるためです
- `overflow: hidden` や高さ 0 で切り取られた内容 (`max-height: 0` で閉じたアコーディオンなど)

次のものは、この機能の有無にかかわらず出力に入りません。get-md が取り出す HTML に含まれないためです: CSS の擬似要素 (`::before`・`::after`・カウンタ) が作る文字、`<canvas>` に描いたもの、`<iframe>` の中身、シャドウ DOM の中身。

### 見えない文字

get-md は、相対 URL を解決する前に、Markdown から次の文字を除きます。

- タブ・LF・CR 以外の制御文字: C0 制御文字、DEL、C1 制御文字 (U+0080〜U+009F)
- Unicode の性質 Default_Ignorable_Code_Point を持つ文字。たとえば次のもの
  - ゼロ幅スペース U+200B、単語結合子 U+2060 と見えない演算子 U+2061〜U+2064、BOM (ゼロ幅ノーブレークスペース) U+FEFF、ソフトハイフン U+00AD、書記素結合子 U+034F
  - 双方向の制御文字: LRM U+200E、RLM U+200F、ALM U+061C、埋め込みと上書き U+202A〜U+202E、分離 U+2066〜U+2069、非推奨の書式文字 U+206A〜U+206F
  - ハングルの埋め字 U+115F・U+1160・U+3164・U+FFA0、モンゴル文字の母音区切り U+180E
  - 異体字セレクタ・ゼロ幅接合子とゼロ幅非接合子・タグ文字 U+E0000〜U+E007F (下の文脈を除く) と、既定で無視する文字として予約された未割り当ての符号位置
- 行間注記の文字 U+FFF9〜U+FFFB

次の文字は残します。

- 見える空白: ノーブレークスペース・細いスペース・極細スペース・狭いノーブレークスペース・全角スペース U+3000 など。行区切りと段落区切り
- 私用領域の文字 (アイコンフォントの字など) と、既定で無視する文字でない未割り当ての符号位置
- 表示される書式文字 (アラビア数字記号 U+0600 など)

既定で無視する文字でも、表示を変える次の文脈では残します。

| 文字 | 残す場合 |
|---|---|
| ゼロ幅接合子 U+200D とタグ文字 U+E0000〜U+E007F | RGI の絵文字の ZWJ の並び (👨‍👩‍👧 など) とタグの並び (イングランド・スコットランド・ウェールズの旗) の中。並びの中の U+FE0F は省いた形でもよい |
| U+FE0E と U+FE0F | 絵文字の異体字の並びを持つ文字の直後 (❤️、#️⃣) |
| U+FE00〜U+FE0D と、モンゴル文字の自由異体字セレクタ U+180B〜U+180D・U+180F | 基底の文字の直後で、その組が標準の異体字の並びにあるとき |
| 漢字の異体字セレクタ (IVS) U+E0100〜U+E01EF | CJK 統合漢字の直後 (葛󠄀)。組が IVD (Ideographic Variation Database) に登録されているかは照合しません |
| ゼロ幅非接合子 U+200C と、絵文字の外のゼロ幅接合子 U+200D | 文字のつながり方を変える場所。UAX #31 の文脈にならい、virama の隣 (デーヴァナーガリーの क्‍ष、シンハラ文字の ශ්‍රී)、つながる 2 文字の間の非接合子 (ペルシア語の می‌خواهم)、つながる文字の隣の接合子で残します。ラテン文字の間などでは除きます |

異体字セレクタは、基底の文字のすぐ後に続く 1 つだけを残します。2 つ目以降の続く異体字セレクタと、前に基底の文字がない異体字セレクタは除きます。異体字セレクタを並べてデータを埋め込む手口があるためです。

- 除く範囲は Markdown の全体です。コードブロックとインラインコード、リンク先、画像の alt と title も対象です。ページの中の `&#x200B;` のような文字参照も、先に文字へ戻してから除きます
- リンク先の見えない文字は、相対 URL を解決する前に除きます。絶対 URL の中にパーセントエンコードされて残ることはありません
- front matter の `title` からも同じように除きます。`--meta` の値は渡したとおりに書きます
- 文字の性質は Unicode 17.0 (get-md に組み込んだ Unicode のデータ)、絵文字の並びと標準の異体字の並びは Unicode 17.0.0 のデータファイルに基づきます

### 表示する数

何かを除いたときは、完了の表示の後に、除いた数を標準エラー出力に 1 行で表示します。

```text
🧹 隠れた要素 3 個・隠れたテキスト 2 か所・見えない文字 12 個 (うち C1 制御文字 4 個) を除いた
```

- **隠れた要素** は、除いた要素のうち、文字か画像を含んでいた一番外側の要素の数です。見えないフォームの欄や空の飾りは数えません。取り出した断片ごとに数えるので、2 つのセレクタに一致した要素は 2 回数えます
- **隠れたテキスト** は箇所の数です。続けて除いたテキストは 1 か所と数えます
- **見えない文字** は Unicode のスカラー値の数で、front matter の title から除いた文字も含みます。C1 制御文字の数は内数で、総数に足したものではありません
- 0 の項目は表示せず、何も除かなかったときはこの行を出しません
- 進捗の表示と同じく、`--quiet` のときや標準エラー出力が端末でないときは表示しません。数は front matter には書きません。ページの描画が少し変わって数だけが変わっても、保存したファイルを書き換えないようにするためです

`opacity: 0` か `visibility: hidden` のために除いた文字が、残した文字と同じかそれより多いときは、`--keep-hidden` を案内する 2 行目 (💡) を表示します。スクロールで内容を表示するページの可能性が高いためです。
